# Section recipes

Invent all copy from the site title and the layers you named in [subject.md](subject.md). Tone follows the object (a keyboard is precise; a lantern is warmer). No lorem ipsum.

There are no scrolling HTML bands. Copy lives in overlay zones that `main.js` hydrates from `siteConfig`.

## Lengths

| Field | Target |
|---|---|
| `tagline` | 6–12 words — also the meta description |
| `mark` | 2–3 letters |
| `wordmark` | 1–2 words |
| `badge` | a spec or year, not "60%" unless that is the object (keyboard form factor) |
| `hint` | 2–4 words, a verb (`Scroll to disassemble`) |
| `hero.eyebrow` | 3–5 words, mono, uppercase |
| `hero.headline` | 1–3 words. Renders at Bebas ~148px. Long words will dominate |
| `hero.subtitle` | 2–6 words, uppercase, tracking out |
| `hero.lede` | 28–45 words |
| `chapters[].kicker` | 3–6 words |
| `chapters[].copy` | 12–22 words |
| `chapters[].body` | 40–70 words |
| `chapters[].facts` | exactly 3, each ≤ 6 words |
| `callouts[].name` | 1–3 words |
| `callouts[].note` | 4–10 words, specs not slogans |
| `colophon.fine` | the layer names joined with ` · ` |
| `colophon.note` | 12–20 words |

## Chapters

Always six, in this arc:

1. **Assembled** — the closed object. `at: 0`. Hero still on screen; this copy is the fallback once the hero fades.
2. **Layer 1** — the first thing that lifts.
3. **Layer 2**
4. **Layer 3**
5. **Layer 4** (or internals / movement / guts)
6. **Exploded** — every layer named, hanging. Invite the reader to scroll back.

If you have five physical layers, merge the quiet ones (foam + standoffs + case) so the list stays at six chapters including assembled and exploded. If you have four, the fifth chapter is still "internals" or "the body".

Do not write testimonials, feature cards, or a gallery of empty tiles. The object is the gallery.

## Imagery

There is none in HTML. Do not search Pexels. Do not download files. The live subject is the imagery; callouts are labels on it. Model the object in [subject.md](subject.md) so what is on screen matches the invented world (a jewelry title should not keep the keyboard).
